# synthlens

Detect whether an image was generated by AI — using **no machine learning**. Detection runs on transparent signal-processing and forensic heuristics (EXIF, Error Level Analysis, noise residuals, FFT spectrum, PRNU-style residual structure, texture/color stats) fused into an explainable verdict with a per-signal breakdown.

Available as a **web UI**, a **REST API**, and a **CLI** — all calling the same detection core.

> Classical heuristics give a probabilistic hint, not proof. They generalize poorly to unseen generators and to post-processing (re-compression, resizing). The `Uncertain` band is real and surfaced on purpose.

## Run with Docker

### Web UI + REST API

```bash
docker compose up --build
```

- Web UI: http://127.0.0.1:8000
- API docs: http://127.0.0.1:8000/docs
- Health: http://127.0.0.1:8000/api/health

Drop your images in `./samples/` (mounted read-only at `/samples` in the container).

### CLI

```bash
docker compose run --rm synthlens synthlens /samples/photo.jpg --verbose
docker compose run --rm synthlens synthlens /samples/photo.jpg --json
docker compose run --rm synthlens synthlens /samples/photo.jpg --save-viz /samples/out
```

## REST API

```bash
curl -F "file=@photo.jpg" http://127.0.0.1:8000/api/detect
```

```json
{
  "verdict": "Likely AI-Generated",
  "probability": 0.78,
  "heuristics": {
    "metadata": { "score": 0.7, "weight": 0.25, "details": { "..." } },
    "ela":      { "score": 0.85, "weight": 0.22, "details": { "..." } }
  }
}
```

## Run locally (without Docker)

```bash
pip install -e .
uvicorn synthlens.server.app:app --port 8000
synthlens photo.jpg --verbose
```

## Signals

| signal | weight | what it measures |
|---|---|---|
| metadata | 0.25 | camera EXIF tags vs. generator software names |
| ela | 0.22 | JPEG re-encode error-level uniformity & blockiness |
| frequency | 0.20 | FFT radial spectrum: 1/f deviation & spectral peaks |
| noise | 0.17 | denoising residual level, uniformity, entropy |
| prnu | 0.10 | residual block correlation (sensor-pattern structure) |
| texture_color | 0.06 | edge density, LBP uniformity, saturation, channel correlation |

Weights and verdict thresholds live in `synthlens/core/scoring.py` and each heuristic module.

## Verdict bands

- `probability < 0.35` → **Likely Real**
- `0.35 – 0.65` → **Uncertain**
- `> 0.65` → **Likely AI-Generated**
